# 🧑‍💻 pkqisgood/portfolio

A clean, responsive, and animated personal portfolio built with **Next.js**, **Tailwind CSS**, and **GSAP**.  
This site showcases my projects, background, and style — with a focus on smooth interactions and honest presentation.

## ✨ Live Demo

👉 [https://pkq.vercel.app](https://pkq.vercel.app)

## 🛠️ Built With

- [Next.js](https://nextjs.org/) – App Router, TypeScript, and server-side rendering
- [Tailwind CSS](https://tailwindcss.com/) – utility-first styling
- [GSAP](https://greensock.com/gsap/) – line and word animations using `SplitType`
- [Framer Motion](https://www.framer.com/motion/) – component-level animations
- SCSS – custom global styles

## 🚀 Getting Started

To run the project locally:

```bash
git clone https://github.com/pkqisgood/portfolio.git
